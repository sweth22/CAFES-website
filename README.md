# ☕ CAFES – Modern Café Website

A fully responsive and interactive café website developed during my internship period to improve my frontend development skills and gain practical experience in web design and user interface development.

The project is built using HTML, CSS, JavaScript, and Bootstrap to create a modern and engaging café experience with multiple pages, interactive layouts, animations, and responsive design.

---

## 📌 Project Overview

CAFES is a frontend-based website designed for a café business. The website provides users with an attractive interface to explore menu items, learn about the café, view gallery images, contact the café, and reserve tables.

This project focuses on:

- Responsive web design
- Interactive UI/UX
- Dynamic page elements
- Multi-page navigation
- Modern layouts and animations
